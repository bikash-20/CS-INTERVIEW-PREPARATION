## Recommended Study Order

If you only have **8 weeks**:

| Week | Focus |
|------|-------|
| 1 | Arrays & Hashing, Two Pointers, Sliding Window |
| 2 | Prefix Sum, Binary Search |
| 3 | Linked List, Stacks & Queues |
| 4 | Trees, BST |
| 5 | Graphs, Union-Find |
| 6-7 | Dynamic Programming (lots of practice) |
| 8 | Backtracking, Greedy, Heap, Trie, Bit Manip, Math, Strings |

**Parallel track:** CS fundamentals (rotate topics every few days).

**Last 2 weeks:** System design fundamentals + 2-3 classic problems daily.
