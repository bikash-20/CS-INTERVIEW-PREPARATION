# Contributing to C++ Interview Mastery

Thanks for your interest in making this repo better! 

## How to Contribute

1. **Fork** the repo
2. **Create a branch** for your contribution: `git checkout -b add-topic-x`
3. **Make your changes** — add a problem, fix a typo, improve an explanation
4. **Test your C++ code** locally:
 ```bash
 g++ -std=c++17 -O2 -Wall your-file.cpp -o your-file && ./your-file
 ```
5. **Commit** with a clear message: `git commit -m "Add: Two Sum II problem in two-pointers"`
6. **Push** and open a **Pull Request**

## Code Style

- Use `C++17` standard
- 4-space indentation (no tabs)
- `using namespace std;` is allowed inside `.cpp` files for brevity
- Each file should be **self-contained** and compilable
- Add a **comment header** at the top of each `.cpp` with:
 - Problem name & LeetCode #
 - Difficulty
 - Approach
 - Time & Space complexity
- Always include a `main()` with at least one example test

## Documentation Style

- Use clear, beginner-friendly language
- Use diagrams (ASCII art is fine) when explaining concepts
- Always include a "Why does this work?" intuition section
- Mention common pitfalls and edge cases

## What to Contribute

- New problems under existing topics
- New topics
- Improvements to existing theory/explanations
- Translations
- Bug fixes

All contributions are reviewed and appreciated!
