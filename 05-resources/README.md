# Curated Resources

A list of trusted resources to deepen your preparation beyond this repo.

---

## Books

### Algorithms & Data Structures
- **"Introduction to Algorithms" (CLRS)** — The classic; covers everything mathematically.
- **"Cracking the Coding Interview" (Gayle McDowell)** — 189 problems, interview-focused.
- **"Elements of Programming Interviews"** — C++/Java/Python versions available.
- **"Algorithm Design Manual" (Skiena)** — Practical and approachable.
- **"Competitive Programming 3"** — For serious contest training.

### System Design
- **"Designing Data-Intensive Applications" (Martin Kleppmann)** — The bible of distributed systems.
- **"System Design Interview Vol 1 & 2" (Alex Xu)** — ByteByteGo; the de-facto standard for SD rounds.
- **"Web Scalability for Startup Engineers"** — Practical scaling patterns.

### C++ Specific
- **"Effective C++" (Scott Meyers)** — 55 specific ways to improve your C++.
- **"Effective Modern C++" (Meyers)** — C++11/14 best practices.
- **"C++ Primer" (Lippman)** — Best beginner-to-intermediate C++ book.
- **"The C++ Programming Language" (Bjarne Stroustrup)** — The reference by the language creator.

### Operating Systems & Networking
- **"Operating Systems: Three Easy Pieces"** (free online!) — Best OS book.
- **"Computer Networking: A Top-Down Approach" (Kurose & Ross)** — Standard textbook.

### Database
- **"Database System Concepts" (Silberschatz)** — Comprehensive DB textbook.
- **"SQL Cookbook"** — Practical SQL patterns.

## Recommended Study Plans

### 8-Week DSA Plan (LeetCode)
1. **Week 1-2:** Arrays, Hashing, Two Pointers, Sliding Window, Prefix Sum.
2. **Week 3:** Binary Search, Linked List, Stacks/Queues.
3. **Week 4:** Trees, BST.
4. **Week 5:** Graphs, Union-Find.
5. **Week 6-7:** Dynamic Programming (lots of practice).
6. **Week 8:** Backtracking, Greedy, Heap, Trie, Bit Manipulation.

### 4-Week System Design Plan
1. **Week 1:** Read "System Design Interview Vol 1" (Ch 1-7).
2. **Week 2:** Read DDIA Chapters 1, 5, 6, 7.
3. **Week 3:** Practice classic problems (URL shortener, Twitter, Uber, etc.).
4. **Week 4:** Mock interviews + your own design (e.g., "design Instagram for me").

### 2-Week CS Theory Refresh
- **Days 1-3:** OS — scheduling, deadlock, memory.
- **Days 4-7:** DBMS — SQL, normalization, transactions.
- **Days 8-10:** CN — HTTP, TCP/IP, DNS, load balancers.
- **Days 11-14:** OOP + C++ specifics — virtual, smart pointers, move semantics.

## Daily Routine Suggestion

- **Morning (1 hour):** 2-3 DSA problems.
- **Lunch (20 min):** Read 1 system design case study.
- **Evening (30 min):** Read CS theory (rotating topics).
- **Weekly:** 1 mock interview.
- **Monthly:** 1 take-home assessment or contest.

---

## Tips

1. **Consistency beats intensity.** 1 hour daily > 7 hours on Sunday.
2. **Understand before memorizing.** Look up patterns, don't just memorize solutions.
3. **Code by hand** occasionally — interviews are whiteboard.
4. **Explain solutions out loud** — practice articulating thought process.
5. **Mock interviews** — the only way to get better at interviews is doing interviews.
